# BX100Y/TX100Y Dual GNSS RTK 测试方案

_适用于北寻 BX100Y/TX100Y Dual GNSS 基准站 + 移动站组合；版本 1.1；用于外场执行、原始数据归档和结果记录。_

---

## 🎯 测试目标与边界

本方案验证以下结论：

> **自主优化基准站条件下的移动站相对定位重复性、局部相对准确度、RTK 固定解可用率与电台中断恢复性能。**

由于无法获得可信控制点，基准站采用自主优化并在测试期间保持不动。因此本方案**不输出绝对全球定位精度**，也不把自主优化坐标当作绝对真值。ENU 坐标原点使用基准站自主优化完成后记录的坐标；该坐标在同一测试会话内保持固定，用于相对距离、闭合差和重复性分析。

本阶段暂不评估杆臂补偿、LIO 融合效果和车体航向安装偏置。双天线安装信息仍需记录，以便后续扩展航向测试。

场地只有一台笔记本，不能同时连接基准站和移动站。因此采用“基准站分时检查、移动站全程记录”的策略：

## 📋 设备、配置与输出消息

### 设备与现场条件

| 项目 | 要求/记录值 |
|---|---|
| 基准站 | BX100Y/TX100Y Dual GNSS，内置电台，单天线，三脚架固定 |
| 移动站 | BX100Y/TX100Y Dual GNSS，内置电台，双天线，小车搭载 |
| 移动站天线 | 主天线左后、从天线右后；记录天线间距和车体方向 |
| 笔记本串口 | 基准站和移动站均使用实际连接的 `COM1`；Linux 设备名暂定 `/dev/ttyACM0` |
| 外部真值 | 无可信全球控制点；局部测试网尺寸由钢尺、测距仪或全站仪独立测量 |
| 测试路线 | 建议 3–5 km 闭环，包含开阔、树荫/遮挡、建筑边和远距区段 |
| 时间 | 记录日期、天气、测试人员、路线、基准站与移动站序列号 |

### 基准站 COM1 配置

自主优化完成后执行并保存配置（具体命令以 BX100 固件手册为准）：

```text
CONFIG PVTALG MULTI
MODE BASE 1 TIME 60 5
SAVECONFIG
```

建议将默认 `COM2` 改为实际采集串口 `COM1`，保留以下消息：

```text
GPGGA COM1 1
GPZDA COM1 1
GPGST COM1 1
TIMEA COM1 1
BESTPOSA COM1 1
GPRMC COM1 1
SATSINFOA COM1 5
GPGSA COM1 3
```

基准站不需要 `HEADINGA` 或 `UNIHEADINGA`。若设备支持独立的电台/RTCM 状态日志（接收计数、丢帧、RSSI 等），按手册配置为 1 Hz，并在记录表中填写实际日志名。

### 移动站 COM1 配置

核心定位和质量消息建议 10 Hz，卫星诊断消息 1/3–5 Hz：

```text
GPGGA COM1 0.1
BESTPOSA COM1 0.1
GPGST COM1 0.1
UNIHEADINGA COM1 0.1
GPZDA COM1 1
TIMEA COM1 1
SATSINFOA COM1 5
GPGSA COM1 3
GNGSVH COM1 3
```

`GPRMC COM1 1` 可选，用于速度和地面航向诊断，但不作为双天线车体航向真值。`HEADINGA` 与 `UNIHEADINGA` 二选一即可，优先使用字段更完整的 `UNIHEADINGA`。

正式测试前，先用目标机按上述配置录制 2–3 分钟预检，确认实际消息类型、频率、CRC、端口头字段、串口带宽和差分状态。首次部署、配置变更或预检接近带宽上限时，再追加 10 分钟串口压力检查，统计完整行、校验失败和行间隔。若波特率不足，优先保证 `GPGGA`、`BESTPOSA`、`GPGST` 和 `UNIHEADINGA`，再降低 `GNGSVH`/`SATSINFOA` 频率。

### 人工事件时间与串口 UTC 对齐

现场人员使用手机或手表记录“到达/离开固定点”“进入/离开树荫”等事件时，通常无法读取接收机 UTC；这些时间应视为**人工注释时间**，不能直接同串口 UTC 比较。每个会话开始和结束时，拍摄一张同时包含手机/手表时间与笔记本系统时间的照片，记录时区；由此建立人工设备时间到笔记本时间的偏移。若会话超过 1 h，建议在中间再拍一次，用于发现时钟漂移。

固定点和路线分段的最终归类优先依据记录后的 ENU 轨迹，而非人工时间：对每个固定点设置半径（例如 1–2 m）地理围栏，并以低速/静止持续时间自动识别到达与离开；对树荫、建筑边和远距区域，在路线图上预先画出 ENU 多边形或起止线，离线按位置自动给每个历元打标签。人工事件时间仅用于复核自动分段是否合理，以及记录轨迹中无法由位置表达的事件（例如人员短时遮挡、电台供电操作）。

## 📍 测试一：固定点静态重复性

### 目的

评估移动站在固定解状态下的短时噪声、不同试次的点位重复性、重新固定时间和解状态连续性。该测试不需要知道 P0/P1/P2 的全球真实坐标。

### 点位与次数

设置 3 个开阔物理点位 `P0`、`P1`、`P2`。每个点位至少完成 3 次独立停靠；测试日另选 P0 做一次 15–20 分钟长静态段，用于观察中期漂移。

### 单次执行步骤

1. 将移动站天线相位中心地面投影停在物理标记点上。
2. 等待 `RTK Fixed` 连续稳定至少 30 s，并记录首次固定时间。
3. 静止记录 3 min；不得在此期间推动小车或改变天线姿态。
4. 离开点位后再返回，重复步骤 1–3。
5. 记录遮挡、人员靠近、车辆经过等事件及手机/手表本地时间；后处理时按“人工事件时间与串口 UTC 对齐”规则换算或复核。

分析时丢弃每次 3 分钟数据的前 30 s，仅使用最后 150 s 的固定解计算稳态统计；前 30 s 仍用于计算重新固定和稳定时间。

| 会话 | 点位 | 第几次 | 开始 UTC | 首次固定 UTC | 固定解样本数 | Float/单点时长 | 备注 |
|---|---|---:|---|---|---:|---:|---|
|  | P0 | 1 |  |  |  |  |  |
|  | P0 | 2 |  |  |  |  |  |
|  | P0 | 3 |  |  |  |  |  |

|  | P1 | 2 |  |  |  |  |  |

|  | P2 | 2 |  |  |  |  |  |
|  | P2 | 3 |  |  |  |  |  |

### 输出指标

对每个点位和每次试验，将经纬高转换为基准站 ENU，报告：

```text
E/N/U 均值或中位数
σE、σN、σU
水平 RMS = sqrt(mean(E² + N²))（相对于该次稳健中心）
水平 95% 离散半径
不同试次稳健中心之间的水平距离和高程差
固定解率、Float/单点/无解时长
BESTPOSA 与 GPGST 标准差的中位数和 95% 分位
```

## 🧱 测试二：局部点位相对准确度

### 目的与测试网

建立一个不依赖全球坐标、但几何尺寸由独立方法测量的临时局部测试网。建议布置 `20 m × 20 m` 矩形四角加中心点：`P0`、`P1`、`P2`、`P3`、`PC`。用钢卷尺、激光测距仪或全站仪独立测量四条边、两条对角线及中心到各角距离，并记录测量不确定度。

### 执行步骤

1. 移动站从 P0 出发，固定解稳定 30 s。
2. 按 `P0 → P1 → P2 → P3 → P0` 完成一圈。
3. 每到一个点，静止 60 s，记录点位进入和离开时间。
4. 至少完成 3 圈；不同时间段再完成 1 圈更好。
5. 如发生降级，保持原始日志连续记录，并在事件表写明状态。

### 计算

对每个点位静止窗口取固定解稳健中心 `x_i = (E_i,N_i,U_i)`，计算：

```text
d_rtk(i,j) = ||x_i - x_j||
距离误差(i,j) = d_rtk(i,j) - d_reference(i,j)
闭合差 = ||x_P0,last - x_P0,first||
```

报告每条边、对角线和中心连线的距离误差均值、RMS、95% 分位；固定解和全部解状态分别统计。独立测量误差必须小于目标精度，否则只能把结果标为“几何一致性检查”。

## 🛣️ 测试三：公里级闭环动态路线

### 路线设计

设计 3–5 km 闭环，包含开阔天空、树荫/轻遮挡、建筑边缘/多路径、逐渐远离基准站的区段。起终点均为 P0，中途设置 P1/P2 停靠点。路线不要求多次完全重合；遥控轨迹差异不作为逐点定位误差。

### 工况与次数

| 工况 | 目的 | 最少次数 |
|---|---|---:|
| 开阔、正常距离 | 基线连续性和固定解率 | 3 圈 |
| 树荫/轻遮挡 | 卫星观测变化与恢复 | 3 圈 |
| 建筑边缘/多路径 | 解状态和位置跳变 | 3 圈 |
| 电台远距或遮挡边缘 | 改正陈旧、Float/单点降级与恢复 | 3 圈，场地允许时 |

### 单圈步骤

1. 在 P0 固定解静止 60 s。
2. 按固定方向完成闭环；中途 P1、P2 各静止 30 s。
3. 返回 P0，固定解静止 60 s。
4. 记录所有路段进入/离开时间、速度变化、遮挡和电台异常。人员记录手机/手表本地时间；树荫、建筑边和远距路段的最终起止历元由 ENU 区段自动判定。
5. 不因暂时降级而停止记录；除非设备、供电或安全出现问题。

### 动态指标

- 全程及分路段的 Fixed/Float/DGPS/Single/No solution 占比
- 解状态切换次数、每次持续时间和空间位置
- 差分龄期超过阈值的次数和持续时间
- 改正中断至解降级时间
- 改正恢复至重新固定时间
- 状态切换前后 ENU 位置跳变量
- P0 起终点闭合差
- P1/P2 多次停靠中心的散布
- 各状态下卫星数、DOP、GST/BESTPOSA 标准差

## 📡 电台中断与解算状态判定

状态判定优先使用 `BESTPOSA` 原始 `solution_status` 和 `position_type`，驱动只做可配置的归一化，不得把未知枚举值强行映射为 Fixed。建议统一为：

```text
FIXED → FLOAT → DIFFERENTIAL/DGPS → SINGLE/AUTONOMOUS → NO_SOLUTION
```

`Tcorr` 为基准站实际播发改正的周期，在 `metadata.yaml` 中填写。默认仅作为待确认参数：

```text
新鲜改正：age ≤ 2 × Tcorr
改正陈旧：age > 2 × Tcorr
疑似中断：age 持续增长并超过 5 s，或接收机明确报告无差分
```

这些阈值必须在首次测试前依据 BX100 日志含义和电台实际配置确认。单点状态持续超过 5 s 才计为一次“有效单点事件”，短暂单个异常样本单独记为数据质量异常。

每次状态事件记录：

| 事件编号 | 开始 UTC | 结束 UTC | 原状态 | 新状态 | 差分龄期 | 最远位置跳变 | 恢复固定 UTC | 环境/备注 |
|---|---|---|---|---|---:|---:|---|---|
|  |  |  |  |  |  |  |  |  |

人工事件可在 `events.csv` 中另存为 `manual_start_local`、`manual_end_local`、`time_source`（手机/手表）、`utc_offset_s` 和 `alignment_quality`；自动根据 ENU 围栏生成的 `start_utc`、`end_utc` 是后续统计的正式字段。

若差分龄期正常但定位降级，优先归类为卫星遮挡、多路径或观测质量变化；只有同时出现差分龄期异常或电台状态异常时，才归类为电台链路问题。

## 🧮 ENU 转换与统计口径

### 坐标原点

使用基准站自主优化完成后记录的 WGS-84 经纬高 `(lat0, lon0, h0)` 作为 ENU 原点。所有移动站坐标使用同一原点转换；基准站不得在会话中移动、重置或再次自主优化。

### 数据分层

每份报告必须同时给出：

1. **全部历元**：表示真实使用时的可用性和解劣化。
2. **仅 Fixed 历元**：表示固定解状态下的定位重复性。

每次刚进入 Fixed 后前 30 s 从稳态精度统计中排除，但保留在重新固定时间和恢复性能统计中。

### 误差与重复性

无外部真值时不使用“绝对误差”命名，使用以下术语：

| 指标 | 含义 |
|---|---|
| 静态散布 | 同一点单次观测相对于自身稳健中心的离散程度 |
| 试次间重复性 | 同一点不同停靠/不同时间段稳健中心之间的差异 |
| 局部距离误差 | RTK 点间距离与独立测量距离的差异 |
| 闭环差 | 回到同一物理点时末点与首点的 ENU 差异 |
| 状态可用率 | 各解算状态占总有效时间的比例 |

`GPGST`/`BESTPOSA` 的标准差是预测不确定度，不是实测误差。将实际静态散布、局部距离误差与其进行覆盖率/一致性比较，用于评估后续 LIO 融合协方差是否可信。

## ✅ 通过判据与异常处理

本阶段不预设厘米级/分米级硬阈值，先建立可重复的基线。每个会话至少应满足：

- [ ] 原始移动站日志连续，行完整率和校验错误率已统计
- [ ] 基准站测试前后状态一致，无未记录的重启或重新自主优化
- [ ] 静态点每次有效窗口包含足够 Fixed 样本
- [ ] 局部测试网的独立测量记录完整
- [ ] 闭环路线的起终点和中途停靠时间可定位到日志
- [ ] 所有状态降级、差分龄期异常和恢复事件均有时间戳
- [ ] 报告区分全部历元与 Fixed 历元

遇到以下情况，停止当前会话并标记为无效或需重测：基准站移动/重启、串口持续丢帧、天线或电台供电异常、测试点被移动、时间戳无法关联、基准站测试前后坐标发生未解释的跳变。

## 📌 测试结论写法

> 在基准站自主优化且测试期间保持不动、单笔记本分时采集条件下，移动站表现出……的相对定位重复性、……的局部相对准确度、……的固定解可用率，以及……的电台中断恢复性能。该结果不代表绝对全球坐标精度。
